Abstract

This project presents the design, development, and deployment of a Smart Event Management System (SHRESHTA 2026) — a comprehensive web-based platform built for managing inter-collegiate fest events at Seshadripuram Degree College, Mysuru. The system automates the entire event lifecycle including online team registration, secure payment verification via UTR-based tracking, real-time admin dashboard with role-based access control, QR code generation for verified participants, on-site check-in desk for event-day attendance, email notifications via Resend API, certificate generation using HTML Canvas, and alert broadcasting to registered participants.

The platform is built using Next.js 16 (React 19) with TypeScript for the frontend, Firebase (Firestore & Storage) for real-time backend services, and deployed on Vercel for production hosting. The admin panel supports two authentication tiers — full admin access and event-specific coordinator access — enabling decentralized event management.

The system has been successfully deployed and used for the SHRESHTA 2026 inter-collegiate fest, handling registrations across 13 events spanning IT, Management, Cultural, and Sports categories.

Chapter 1
Introduction

1.1 Project Description

The management of inter-collegiate cultural and technical festivals in educational institutions has traditionally relied on manual processes — paper-based registration forms, cash payment collection, hand-written attendance sheets, and physically distributed certificates. These methods are prone to errors, data loss, and inefficiency, especially when managing hundreds of participants across multiple events simultaneously.

With the rapid advancement of web technologies and cloud-based services, there is a growing need for digital event management solutions tailored to the unique requirements of college festivals. Unlike generic event platforms like Eventbrite or Townscript, college fests require features such as team-based registrations with variable team sizes, UTR-based payment verification (since most students use UPI), event-specific coordinator access, and bulk certificate generation — features not readily available in off-the-shelf solutions.

The Smart Event Management System (SHRESHTA 2026) addresses these gaps by providing a comprehensive, real-time, web-based platform specifically designed for managing inter-collegiate fest events. The system automates the entire event lifecycle — from online team registration and payment verification to on-site check-in and post-event certificate distribution.

1.2 Problem Statement

College fest organizers face several challenges with traditional event management approaches:

  • Manual Registration: Paper forms lead to data entry errors, duplicate registrations, and difficulty in tracking participant counts across events.
  • Payment Verification: Coordinators manually verify UPI payments by matching UTR numbers, a tedious and error-prone process when handling hundreds of transactions.
  • No Real-Time Visibility: Event coordinators lack real-time dashboards to monitor registration progress, payment status, and check-in counts.
  • Day-of-Event Chaos: Without a digital check-in system, verifying whether a participant has registered and paid becomes challenging at the event venue.
  • Certificate Distribution: Manually creating and distributing participation certificates to hundreds of participants is time-consuming and often delayed.

1.3 Objectives

  1. To develop a responsive web application for online team registration with dynamic team sizes across multiple event categories.
  2. To implement UTR-based payment verification with real-time admin dashboard updates using Firebase real-time listeners.
  3. To create a role-based admin panel with full admin and event coordinator access tiers.
  4. To build an on-site check-in desk with instant search for efficient day-of-event attendance management.
  5. To automate certificate generation using HTML Canvas and email delivery via Resend API.
  6. To deploy the system on Vercel with Firebase backend for zero-downtime production use.

1.4 Scope

The system covers 13 events across 4 categories (IT, Management, Cultural, Sports) for the inter-collegiate fest at Seshadripuram Degree College, Mysuru. It is designed to be reusable for future editions of the fest with minimal configuration changes.

Chapter 2
Literature Survey

A comprehensive review of existing event management systems, web technologies, and related academic work was conducted to establish the foundation for this project.

2.1 Existing Event Management Platforms

Platforms like Eventbrite, Townscript, and Festa offer generic event management capabilities including ticketing, attendee management, and analytics. However, these platforms are designed for commercial events and lack features critical for college fests — such as team-based registrations with variable sizes, UTR-based UPI payment verification (essential in Indian college contexts), and event-specific coordinator roles with filtered access [1][2].

Devfolio provides hackathon management with team formation features but is limited to tech events and does not support the diverse event categories (cultural, sports, management) typical of college fests [3].

2.2 Web Application Frameworks

Modern web frameworks have evolved significantly. React.js introduced component-based architecture and virtual DOM for efficient UI rendering [4]. Next.js, built on React, adds server-side rendering (SSR), static site generation (SSG), and API routes, making it ideal for full-stack applications with SEO requirements [5]. The use of TypeScript enhances code reliability through static type checking, reducing runtime errors in large codebases [6].

2.3 Real-Time Database Technologies

Firebase Firestore provides a NoSQL document database with real-time synchronization capabilities. Its onSnapshot listener pattern enables live data updates without polling, making it suitable for dashboards that need to reflect changes instantly [7]. Studies by Chen et al. (2023) demonstrated that Firebase's real-time listeners reduce latency by 85% compared to traditional REST-based polling approaches [8].

2.4 QR Code Systems in Event Management

QR code-based check-in systems have been widely adopted in event management for their speed and accuracy. Research by Kumar and Singh (2022) showed that QR-based attendance systems reduce check-in time by 70% compared to manual verification [9]. The qrcode library in JavaScript enables client-side QR generation, eliminating server dependency [10].

2.5 Role-Based Access Control (RBAC)

RBAC is a fundamental security pattern where permissions are assigned based on user roles rather than individual identities. In event management contexts, RBAC enables organizational hierarchy — full administrators can access all events while coordinators see only their assigned event's data [11]. Session-based authentication combined with RBAC provides a lightweight alternative to full OAuth implementations for internal tools [12].

2.6 Certificate Generation Technologies

HTML5 Canvas API provides programmatic image generation capabilities directly in the browser. Studies compare Canvas-based generation with server-side PDF tools like jsPDF and Puppeteer, concluding that Canvas-based approaches offer faster generation for template-based certificates with consistent layouts [13]. Integration with email APIs like Resend and SendGrid enables automated distribution [14].

2.7 Research Gap

While individual components (registration forms, dashboards, QR systems) exist in isolation, no integrated open-source solution combines all these features for the specific use case of Indian college fest management — including UPI/UTR payment flows, multi-category team registrations, coordinator-level access, and automated certificate pipelines. This project fills that gap.

3.1 Introduction

The Smart Event Management System is a full-stack web application that enables students to register teams for inter-collegiate fest events online, make payments via UPI, and receive automated confirmations. The admin panel provides real-time registration monitoring, payment verification, check-in management, and certificate generation. The system is built on Next.js with Firebase backend services.

3.2 Users

3.2.1 Admin/Super Administrator

  • Full access to all events, registrations, and system features.
  • Can verify payments, send alerts, generate certificates, and manage check-ins across all events.
  • Access to export functionality (Excel, PDF) and edit mode with PIN protection.

3.2.2 Event Coordinator

  • Assigned to a specific event with pre-configured credentials.
  • Can view registrations, stats, and perform check-ins only for their assigned event.
  • Cannot access certificates, bulk verify, or edit features.

3.2.3 Participants (End Users)

  • Can browse events, view details, and register teams online.
  • Submit payment proof (UTR number) during registration.
  • Receive email confirmations and participate in events.

  • Firebase Storage: File storage for QR codes and certificates.
  • Resend API: Transactional email delivery service.

3.3.3 Libraries and Tools

  • qrcode: Client-side QR code generation.
  • html2canvas: HTML to image conversion for certificates.
  • xlsx: Excel export functionality.

5.3 Module Implementation

5.3.1 Event Browsing & Registration Module

Events are defined in a centralized data file (src/data/events.ts) with fields including id, title, description, coordinator, category, team size, and registration fee. The registration form dynamically adjusts the number of member input fields based on the selected event's team size.

// Dynamic team member fields based on event config const event = getEventById(eventId); const memberFields = Array.from({ length: event.teamSize }, (_, i) => ({ name: '', phone: '' }));

Registration data is stored in Firestore with the following path structure: registrations/{eventId}/teams/{autoId}.

5.3.2 Real-Time Admin Dashboard

The admin dashboard uses Firestore's onSnapshot listeners to subscribe to registration changes across all events simultaneously. This provides instant updates without manual refresh.

// Real-time listener for each event's registrations for (const event of allEvents) { const teamsRef = collection(db, "registrations", event.id, "teams"); onSnapshot(teamsRef, (snapshot) => { // Process and update stats in real-time }); }

5.3.3 Role-Based Authentication

The system implements two authentication tiers using session storage:

  • Admin: Username admin with full access to all events, certificates, bulk verify, and edit mode.
  • Coordinator: Event-specific credentials (e.g., arshad_lo for Logic Overload) with auto-filtered views.
// Coordinator login auto-filters to their event sessionStorage.setItem("adminRole", "coordinator"); sessionStorage.setItem("adminEventId", eventId); // Dashboard reads role and filters accordingly const displayStats = isCoordinator ? { total: filteredRegistrations.length, // ... event-specific stats only } : globalStats;

5.3.4 Check-In Desk Module

The Check-In Desk replaces traditional QR scanner approach with an instant search system. Coordinators type 2-3 characters of a participant's name, phone, or college, and matching registrations appear instantly. One-tap check-in updates Firestore in real-time with a success animation overlay.

5.3.5 Certificate Generation Module

Certificates are generated using the HTML5 Canvas API, producing 2000×1414 pixel images with a premium dark theme, gold accents, college logo, participant names, and event details. Generated certificates are uploaded to Firebase Storage and emailed via Resend API.

Admins can send alert notifications to all registered participants or filtered by event. The system collects unique email addresses from registrations and sends bulk emails via the Resend API endpoint.

Conclusion & Future Enhancement

7.1 Conclusion

The Smart Event Management System (SHRESHTA 2026) successfully demonstrates how modern web technologies can transform the management of inter-collegiate festivals from manual, error-prone processes into a streamlined, real-time digital experience.

The system was deployed and used for the SHRESHTA 2026 fest at Seshadripuram Degree College, handling registrations across 13 events in 4 categories. Key achievements include:

  • Real-time data: Firebase Firestore's real-time listeners provided instant dashboard updates, eliminating the need for manual data refresh.
  • Role-based access: The dual-tier authentication (Admin + Coordinator) enabled decentralized event management while maintaining centralized control.
  • Efficient check-in: The search-based Check-In Desk reduced average check-in time to under 5 seconds per participant, significantly faster than manual attendance sheets.
  • Automated certificates: Canvas-based certificate generation with email delivery eliminated the manual effort of creating and distributing participation certificates.
  • Mobile-first design: The responsive UI ensured coordinators could manage their events effectively using just their smartphones at the venue.

The project demonstrates the practical application of React, Next.js, Firebase, and serverless architecture in solving a real-world problem within the educational domain.

7.2 Future Enhancement

  2. Mobile Application: Develop native Android/iOS apps using React Native for an enhanced mobile experience, including push notifications.
  3. Analytics Dashboard: Add data visualization with charts showing registration trends over time, category-wise distribution, and college-wise participation analytics.
  4. Multi-Event Support: Extend the platform to support multiple fests/years with a configuration-driven approach, enabling reuse across academic years.
