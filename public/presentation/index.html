1. Abstract

  • The Problem: Hosting large-scale inter-collegiate fests involves massive logistical hurdles—long queues, paper-based tracking, manual payment verification, and delayed certificate distribution.
  • The Solution: We developed the "Smart Event Management System" (SHRESHTA 2026) to completely digitalize this physical process.
  • Key Features:
    • Real-time cloud synchronization
    • Automated QR-code-based ticketing & check-ins
    • Role-based operational dashboards
  • Impact: Achieved 100% paperless management, reduced physical check-in time to under 5 seconds, and provided real-time transparency for administrative decisions.

2. Introduction

The Current Context

Event management in educational institutions heavily relies on manual workflows like Excel sheets and standalone Google Forms, which are inefficient for multi-tier events.

  • Duplicate data entries and human errors.
  • Verification of financial payments (UPI/UTR) is historically tedious.

Our Unique Approach

By leveraging modern web technologies like Next.js and Firebase Serverless computing, we built a centralized, dynamic application that handles everything autonomously:

  • From initial team registration & payment gateway integration...
  • To the final automated dispatch of digital HTML Canvas-based participation certificates.

3. Literature Review

  • Traditional Methods: Pen-and-paper physical registrations lack structural integrity and rely heavily on volunteer accuracy under pressure.
  • Existing Platforms (e.g., Eventbrite, Townscript): While powerful, international ticketing platforms are often too generic, costly (taking transaction cuts), or rigid for the specific requirements of college-level fests.
  • Institutional Specifics: Existing platforms fail to handle dynamic team sizing constraints, UTR capturing workflows, and college-name tracking correctly.
  • The Technological Gap: There is a severe lack of lightweight, real-time, customizable digital solutions specifically tailored for academic institutions that include end-to-end automation without high infrastructure costs.

4. Research Methodology

System Architecture

  • Frontend Environment: Next.js (React 19) and Tailwind CSS for a highly responsive, mobile-first interface suitable for field coordinators.
  • Backend Ecosystem: Firebase Firestore (NoSQL cloud database) for sub-second live data streaming.
  • Automated APIs: Integration with Resend Email API for triggering automated verifications.

Execution Framework

  • Agile Development: Allowed continuous, live feedback integration from faculty coordinators directly from the campus.
  • Security Paradigm: Implemented strict Role-Based Access Control (RBAC). A photography coordinator cannot manipulate data for a coding competition, ensuring pure data isolation.

5. Objectives & 6. Results

Core Objectives

  1. Eliminate Paper Trails 100%.
  2. Optimize Physical Efficiency: Cut check-in queue times utilizing search & QR technology.
  3. Automate Manual Labor: Deploy an overarching UTR payment workflow and zero-touch certificate generation.

Real-World Results

  • Successfully absorbed and structured concurrent registrations across 13 distinct categorized events.
  • The "Scanner Desk" feature successfully reduced the average participant verification time to exactly under 5 seconds.
  • Zero Data Overlap: The isolated dashboard architectures produced a 0% data mishandling and collision rate throughout the entire fest.

7. Conclusion & 8. References

Conclusion

The SHRESHTA Smart Event Management algorithm explicitly proves that monolithic event-handling procedures can be entirely replaced by scalable, serverless micro-architectures. By prioritizing a seamless UI/UX alongside military-grade cloud frameworks, we reduced systemic friction for participants and staff alike—creating a reusable asset for future academic years.
